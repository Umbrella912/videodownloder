CLIPNEST · USER GUIDE

How to use Clipnest.

A quick guide to opening the app, choosing your media, and saving your downloads.

GET STARTED

1. Open Clipnest

  1. Double-click Clipnest-autoport.exe each time you want to use it. It is a launcher, not a conventional installed Windows app. If you choose Shortcuts…, a separate copy is placed in your user profile for the shortcuts.
  2. If Python is missing, click Setup guide in the launcher and follow the instructions. Once Python is installed, return to the launcher and click Check & start. Clipnest installs its Python dependencies automatically; the first start may take a few minutes and needs internet.
  3. Wait for Clipnest to open in your browser. If needed, click Open Clipnest. Keep the launcher open while using it.

If port 3000 is occupied, the launcher automatically tries another available port.

THE BASICS

2. Download media or audio

  1. Copy a supported public link from YouTube, Instagram, Twitch, TikTok, or Facebook and paste it into the link field.
  2. Click Get media to inspect the link and see available options. You can also click the download button directly; Clipnest will inspect it first.
  3. Choose Video or Audio only, then select the available quality. Instagram media uses the available original quality; audio is saved as MP3 when available.
  4. Click Download video, Download media, or Download audio, and wait. Once ready, your browser should save the file. If it doesn't, use the Save file link in the success message.

Look in your browser's usual Downloads folder. The launcher also keeps a working copy in %LOCALAPPDATA%\Clipnest\downloads.

OPTIONAL

3. Select a section

For a supported recorded video, check Download a specific section. Enter a start and an end time, for example 00:30 and 02:15. You can use seconds, MM:SS, or HH:MM:SS, and the sliders when available. The end must be after the start and within the video. Leave the box unchecked to download the whole item.

On Instagram carousels, the same range is applied to each video; photos are skipped and the range must fit every video. Instagram may download the original video before trimming. Timestamp selection is not available for live streams.

More tips

  • Theme: use the theme button at the top of the Clipnest page to switch between light and dark.
  • Live content: where supported, Clipnest records approximately one minute. Some streams may not be accessible.
  • Instagram: accessible photos, videos, Reels and carousels can work; multiple items may be saved in a ZIP. Stories generally require login; Instagram Live is not supported.
  • Availability: private, restricted, deleted, or platform-blocked media may not work. TikTok photo slideshows and Facebook photo-only posts are not supported. Quality depends on what the platform provides.
  • Chrome extension: the previously supplied extension connects only on port 3000. If the launcher chooses another port, use the browser page instead.
  • Remove Clipnest: close it and delete the EXE. The app files, Python environment and downloads remain in %LOCALAPPDATA%\Clipnest; back up downloads before deleting that folder. If you created shortcuts, delete those separately; their launcher copy is inside the Clipnest folder.

Only download content you have permission to use. Respect creators and platform terms.
